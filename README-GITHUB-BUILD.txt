PIEFI V3 GITHUB ACTIONS BUILD

This bundle contains PieFi V3 source and a GitHub Actions firmware build workflow.

1. Upload these files/folders into your repository (root), replacing the old inventory-only workflow if desired.
2. Open GitHub repository > Actions.
3. Select "PieFi V3 Firmware Build" > Run workflow.
4. Wait for the run to finish.
5. If green, open the run and download artifact "PieFi-OS-Lite-V3-firmware".

A green build is not proof of boot or hardware function. Test the image on a spare device first.
